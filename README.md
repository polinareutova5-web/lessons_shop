# Telegram-магазин презентаций (MVP)

Стартовый проект: Telegram-бот на Python + ЮKassa + Google Sheets + SQLite.

## Возможности
- каталог материалов из Google Таблицы;
- карточка материала и предпросмотр по прямой ссылке;
- создание платежа ЮKassa с redirect-подтверждением;
- webhook `payment.succeeded` с обязательной повторной проверкой платежа через API ЮKassa;
- сверка суммы, валюты и `metadata.order_id`;
- защита от повторной выдачи одного заказа;
- отправка файла покупателю;
- команда `/orders` для администратора.

## Важно
Это заготовка для тестирования и дальнейшей настройки, а не готовый к публичному запуску платёжный сервис. Реальные платежи и коммерческий аккаунт ЮKassa должны оформляться и контролироваться совершеннолетним владельцем/законным представителем с соблюдением условий сервиса и применимых требований. Не публикуйте токены и ключи и не присылайте их в чат.

## 1. Установка
Python 3.11+.

```bash
python -m venv .venv
# Windows: .venv\Scripts\activate
# macOS/Linux:
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
```

Заполните `.env`.

## 2. Google Sheets
1. Создайте таблицу и лист с названием `Products`.
2. Добавьте в первую строку заголовки строго в таком порядке:

| product_id | title | description | price_rub | preview_url | file_url | active | category |
|---|---|---|---:|---|---|---|---|

3. Создайте Google service account, скачайте JSON-ключ и сохраните его как `service-account.json` рядом с `.env`.
4. Поделитесь таблицей с email сервисного аккаунта с правами читателя.
5. Включите Google Sheets API в проекте Google Cloud.
6. В `.env` укажите `GOOGLE_SHEET_ID`.

`preview_url` и `file_url` должны быть прямыми HTTPS-ссылками на скачиваемые файлы, доступными серверу без авторизации. Обычная ссылка на страницу предпросмотра Google Drive может не подойти. Для закрытых материалов лучше позже добавить интеграцию с Google Drive API и скачивание через OAuth/service account.

`active` принимает `TRUE` или `FALSE`. Цена указывается числом в рублях, например `299`.

## 3. Telegram
Создайте бота через официальный интерфейс Telegram для управления ботами и скопируйте токен в `BOT_TOKEN`.
Укажите свой Telegram numeric ID в `ADMIN_IDS` (несколько ID через запятую).

## 4. ЮKassa
Для локальной разработки используйте тестовые данные магазина. В `.env` укажите `YOOKASSA_SHOP_ID`, `YOOKASSA_SECRET_KEY` и публичный HTTPS `PUBLIC_BASE_URL`.

После развёртывания укажите в настройках HTTP-уведомлений ЮKassa адрес:

`https://ВАШ-ДОМЕН/yookassa/webhook`

Подпишитесь на `payment.succeeded`. Возврат пользователя на `RETURN_URL` сам по себе не считается подтверждением оплаты: выдача происходит только после webhook и серверной проверки статуса платежа.

## 5. Запуск
```bash
python -m app.main
```

Бот использует long polling, а FastAPI принимает webhook на том же процессе. Для публичной работы нужен постоянно работающий сервер с HTTPS-доменом/прокси и постоянным диском для SQLite. Не используйте локальный компьютер как production-хостинг.

Проверка health:
`https://ВАШ-ДОМЕН/health`

## Команды бота
- `/start` — открыть магазин
- `/catalog` — каталог
- `/orders` — последние заказы (только администратор)

## Перед реальным запуском обязательно доделать
- налоговые/кассовые требования, оферту, политику возвратов и обработку персональных данных;
- ограничение частоты запросов, логирование и мониторинг;
- проверку URL файлов и безопасное хранилище вместо публичных ссылок;
- резервное копирование SQLite или переход на PostgreSQL;
- тестирование возвратов, отмен, повторных webhook и ошибок Telegram;
- согласовать схему Google Sheets и права доступа;
- добавить админский интерфейс для загрузки/изменения материалов.

## Структура
- `app/main.py` — бот, платежи, webhook, БД и Google Sheets.
- `.env.example` — список настроек.
